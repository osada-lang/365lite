# 365LITE (365ライト)

Googleビジネスプロフィール（GBP / Googleマップ）への**最新情報・毎日自動投稿システム**です。

---

## 🌟 主な機能

1. **Gemini AIによる日替わり最新情報自動生成**
   * PREP法に基づいた結論ファーストの構成
   * 6つの日替わりテーマ（悩み解決、サービス紹介、利用シーン、FAQ、選ばれる理由、ターゲット特化）
   * メインキーワード（5つ）および日替わりサブキーワード（2〜3語）の自然な自動組み込み
   * スマートフォン可読性の最適化（短い段落・空行の自動フォーマット）
   * CTA（「詳細」ボタン誘導）の一文自動付与

2. **Google Driveリアルタイム写真ストック連携**
   * 店舗専用Google Driveフォルダとのリアルタイム双方向同期
   * サブキーワードとDrive内サブフォルダ名のインテリジェントマッチング
   * フォルダ指定アップロードおよび削除機能

3. **投稿動作モードの自動最適化**
   * 画像0枚: テキストのみ投稿モード
   * 画像1〜9枚: 交互投稿モード（画像ありとテキストのみを日替わりでローテーション）
   * 画像10枚以上: 連続画像投稿モード（順次画像をローテーション）

4. **3日分の予約下書き管理**
   * 3日先までのAI下書きの確認・手動編集・個別再生成・一括再生成

5. **マルチテナント管理**
   * マスター管理者（ADMIN）、代理店（AGENCY）、店舗オーナー（OWNER）の3段階権限
